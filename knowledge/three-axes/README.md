## 使用顺序

1. 选环境：月收盘在月 MA10 同侧；周、日收盘在各自 MA10 同侧且周日 MA10 同向。缺少足够完成K线为未知，不共振为不做。
2. 严格止损：TR=max(高-低,abs(高-前收),abs(低-前收))，ATR14 为14根TR均值。1.5×ATR只是上游参考，不能替代真实结构失效点，不允许为等待解套扩大风险。
3. 以损定量：风险手数=向下取整(权益×风险比例/(入场与止损价差×合约乘数))；名义敞口手数=向下取整(权益×敞口比例/(入场价×乘数))；取小。缺权益、乘数、参数和组合持仓时不输出建议手数。

## 小木适配与冲突

- 上游使用新浪主力连续；小木使用 TqSdk 实际月份合约，未完成日K排除，周月保守排除首尾周期。不拼接换月来凑历史。
- 研究池成交量、持仓量均须严格大于1万手。价格和涨跌采用收盘/前收盘，不能使用结算替代。
- 上游500万元、1%风险、10%敞口是示例参数，不是用户账户配置。单品种上限不代表组合风险已通过。
- 上游把价涨增仓等解释成主动多空；小木只描述价仓变化，不能仅凭总持仓推断交易者意图或净资金流。
- 月周日共振只是环境筛选，未核验五简的日K触发、平台结构、产业证据、反证与风险门时，只能称观察候选。
- 上游关于胜率改善的文字没有在小木验证，不作为已证实收益或概率。
- 本条目仅适用于国内期货。不能把期货合约乘数、做空机制与持仓量门槛直接用于股票。

## 输出标准

先说明行情状态、报价/完成K线日期与覆盖范围；再列环境方向、结构证据、ATR参考、最强反证、待补项和下一检查点。无合格候选时明确空缺，不补名额；旧报价只作对应日期研究，不叫实时推荐。默认不输出交易许可或自动下单。
