# 五简 JARVIS 全息工作台 v1.0

本地 Web 原型，2026-09-18。蓝色全息驾驶舱、中央地球、可交互语音球与五行交易工作流。所有行情、图形、定位与计划均为演示，不是实时行情或业绩。

## 启动

需要 Node.js 22 以上。在本目录执行 `npm start`，然后打开 http://127.0.0.1:4318 。也可双击 `启动工作台.command`。服务已经运行时直接打开网页，不必重复启动。关闭终端或按 Ctrl+C 停止服务。

## 已能使用

- 驾驶舱：选择品种、核心/观察过滤、月周日示例图、证据卡与模拟计划审阅。
- 火水金土木：机会扫描、结构分析、人工决策记录、执行状态、复盘入口。
- 本地研究后端：对确定性演示序列计算 MA10，返回任务结果；切换页面和收起对话不会中断任务。
- 文字指令：扫描机会、分析当前品种、检查风险、复盘记录。
- 决策存储在 `.runtime/decisions.json`；任务仅保留在服务进程内，重启后清空。
- 专注模式、减少动画、窄屏重排。

## 电话式交互

点击中央能量球打开对话面板。可收起对话继续操作工作台。

本地体验提供浏览器语音识别与朗读，识别固定指令；浏览器不支持时用文字输入。识别服务可能需要联网，具体取决于浏览器。此模式为轮流说话，不是完整的自然 AI 通话。

AI 实时通话已预留 WebRTC 音频、静音/挂断、工具调用与后台研究的连接实现。复制 `.env.example` 为 `.env`，只在本机填入自己的 OPENAI_API_KEY，重启服务后选择“AI 实时通话”。不要将密钥发到聊天或填入网页。语音和对话将发送至 OpenAI，可能产生 API 费用。服务端保存密钥，浏览器不获取密钥。

官方接入依据：[Realtime WebRTC 文档](https://developers.openai.com/api/docs/guides/voice-webrtc)。本次未配置 API 服务，因此未验证真实双向音频、打断与麦克风权限；不能把接口实现视为已接通电话。

## 当前边界及下一步

真实行情、IMA 在线检索、账户、订单通道未接入；官网链接是来源入口，不代表自动抓取已实现。贝叶斯更新只有规划入口，无真实交易样本、后验结果或自动参数调整。模拟批准只写记录，不下单。

下一步先接官方行情与可复核来源、交易日历和换月，再导入当前规则与证据；之后完成回放与模拟验证。真实执行、风险额度及发布新规则仍由人工拍板。Web 稳定后再封装桌面应用。

## 文件结构与来源

`dist/` 为前端，`server.mjs` 为本机服务，`data/market.json` 为演示数据。无需 npm 依赖，字体使用系统回退，驾驶舱背景在本地。

来源：用户提供的 JARVIS 参考图；同日《五简JARVIS建设计划》；工作台 D025、D027、D029、D030 决策。界面采取火→水→金→人工拍板→土→木流程。背景经图像工具按参考图重建，不含文字/图表，所有面板都是 HTML 可操作组件。

本版状态：验证中。复盘入口：页面“木·复盘迭代”与本文件验证记录。


## v1.1 · Three.js 全息升级（2026-09-18）

使用本地固定版本 Three.js 0.180.0。中央地球与语音球为两个真实 WebGL 场景，包含大陆纹理、Fresnel 边缘光、扫描线、星点、倾斜轨道及底部投影环。地球支持拖动旋转。连接状态改变语音球颜色；本地朗读有呼吸反馈，不代表真实音量频谱。待配置语音服务的边界保持不变。

桌面与窄屏自适应；渲染限制约 30 FPS / 1.5 DPR，隐藏窗口或离开可视区域时跳过渲染，尊重减少动画设置。WebGL 不可用时保留静态界面。后续可把几何球体替换为用户提供的 GLB 模型，当前未接入外部模型。

新增 `dist/hologram.js`。Three.js 许可证见 `dist/vendor/THREE-LICENSE.txt`；官方技术文档 https://threejs.org/docs/ 。地球纹理来源 https://github.com/turban/webgl-earth/blob/master/images/2_no_clouds_4k.jpg （Blue Marble 示例资源）；本地保存，无运行时 CDN 依赖。本版未公开发布。

验证：修正了首轮 GLSL 保留字编译错误，重新加载后两处 WebGL 场景正常绘制；大陆纹理可见，三维语音球点击可打开对话，原有行情与研究功能保留。
