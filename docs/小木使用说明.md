# 小木工作台使用说明

版本：2026-10-09 手动保存复盘版。适用：Windows 10/11，64位 x64。

## 第一次打开

1. 先将整个压缩包解压到一个可写文件夹，建议 D 盘。不要在压缩包预览窗口里启动。
2. 双击最外层的 `启动小木.cmd`。保留文件夹结构，不要单独移动 EXE。
3. 默认实盘账户的实际金额为空。点顶部账户旁的添加按钮，输入自己的账户名称和金额。包中不含原作者账户、成交或私人复盘。
4. 本包附带 2026-10-09 的公开行情快照，仅作首次查看。使用时以页面行情日期、缺口和刷新状态为准，不能当成今天的数据。

应用自带 Electron / Node 和 Python 行情环境，普通使用不必安装编程工具，不需要管理员权限。首次打开可能收到 Windows 未签名应用提示；仅在核实来源和压缩包校验值后选择是否运行，不要关闭系统安全防护。

## 每日顺序

- 火：点击“刷新盘后数据”，核对目标交易日、已同步数量和缺口。切换月周日共振、月周大周期、周日小周期；查看具体合约和详情，选择品种进入水研究。
- 盘后数据复盘：在火页面点“盘后数据复盘”，分析当前选中的周期。名单、规则和行情先固定，再计算价量仓指标。未配置AI仍显示真实计算，不编造新闻原因。
- 保存复盘：分析完成后点窗口右侧“保存复盘”。不点就不写入复盘历史；关闭弹窗后本次运行内仍可查看，重新分析会产生新的未保存结果。退出程序后未保存结果不保留，服务最多保留最近20次临时分析。
- 找回报告：点“盘后数据复盘”左侧的“已保存复盘”，下拉列表按保存时间从新到旧排列。旧版自动保存的记录按生成时间保留。不因查看历史重新调用AI。重复点保存不会重复生成文件。
- 水：用四问补充基本面证据；配置自己的模型后，可启动AI深度研究。研究是草稿，不是交易许可。
- 金：核对账户、主周期、自动环境、入场止损配对。填写入场和止损价，按账户金额与亏损比例计算手数；冻结后人工批准。实际成交以交易软件为准。
- 土：记录开仓时间、均价、数量、保护与异常、退出原因、实际盈亏。方向沿用计划；真实发生的异常成交也应如实记录。
- 木：核对盈亏和账户变化，写“做得好、做得不好、下次注意”。本轮启动后规则不临时更换，结束并复核后再调整下一轮。

系统不自动下单。日K触及止损价只能提示核验，不能证明成交。收盘、结算和昨收不是同一个口径；免费源延迟、失败、缺数据会明确提示，不能保证每天固定时点全品种齐备。

## 保存在哪里

以下路径均相对解压后的最外层文件夹：

| 内容 | 位置 |
| --- | --- |
| 完整项目源码 | `小木工作台\wujian-jarvis` |
| 桌面程序 | `小木工作台\wujian-jarvis\.runtime\desktop-build\小木-win32-x64\小木.exe` |
| 手动保存的盘后复盘 | `小木工作台\wujian-jarvis\.runtime\postmarket-reviews\记录ID` |
| 每份复盘正文 | 上述记录目录内的 `复盘报告.md` |
| 复盘计算与输入快照 | 同目录的 `result.json`、`input.json`、`status.json` |
| 账户、计划、成交、复盘业务库 | `小木工作台\wujian-jarvis\.runtime\five-workbench.sqlite` |
| 可供AI继续复盘的操作记录 | `小木工作台\wujian-jarvis\操作记录` |
| 行情缓存和具体合约日K | `小木工作台\wujian-jarvis\.runtime\fire-scan` |
| 规则与技能资料 | `小木工作台\资料包`，以及根目录 `1_交易` 内的职责框架 |

保存报告后，窗口底部也显示它的实际绝对路径。备份前正常关闭小木，待几秒后复制整个文件夹，避免只复制一个尚在写入的SQLite文件。恢复时解压备份后从备份目录启动；不要在运行时直接覆盖数据。

## 配置自己的AI（可选）

分享包不附带任何人的API密钥，也不共用原作者的付费账户。未配置AI不影响图表、筛选、填写、计算、手工记录和计算型盘后复盘。

1. 到 `小木工作台\wujian-jarvis`，将 `.env.example` 复制为 `.env`，不要误存成 `.env.txt`。
2. 用文本编辑器填写 `DEEPSEEK_API_KEY=你自己的密钥`，并按服务商实际可用型号填写 `DEEPSEEK_MODEL`。
3. 完全退出小木，再重新打开。AI研究与复盘解释可能产生服务商调用费用。

语音、飞书、IMA、天勤等是可选独立连接，均需接收者自行配置自己的凭据和权限；本包不包含作者的订阅、登录态、实时行情权限和本地向量模型缓存。IMA可通过 `WUJIAN_IMA_CLIENT` 指向自己的客户端脚本；未连接的来源只能显示缺口。天勤需另装其Python环境，包内现成的是免费盘后行情环境。

## 常见情况

- 打不开：先确认已完整解压，文件夹可写，EXE及其旁边DLL没有被单独挪走；若提示4318端口占用，关闭此前的小木，待退出后再开，不要强行结束不认识的进程。
- 数据旧：先刷新，查看目标交易日与错误提示。夜盘不意味着当日日K应被改成下一交易日完成K；缺口不能当成筛选不通过。
- 保存失败：检查磁盘空间和文件夹权限，保留窗口，点“重试保存”。未成功保存的报告不进历史。
- AI失败：真实计算仍可查看和保存；检查自己的模型、余额、网络后再分析。查看旧报告不收取新的模型费用。
- 再次分享：不要压缩已经使用过的整个目录，否则可能带上自己的 `.env`、账户和操作记录。重新运行干净分享打包脚本，或使用最初收到的干净压缩包。

## 给开发维护者

当前开发版新增“盯盘提醒”，见 [盯盘 Agent 使用与恢复](monitor-agent.md)。行情与手机通知须本人在 APP“连接与通知”配置，密码不发到聊天。旧分享 ZIP 未重新构建，不代表已携带当前实时监控运行库或功能。

源代码、前端静态资源、Python工具、测试、锁定依赖清单及所需规则资料一并提供。前端入口为 `dist/index.html`，服务入口为 `server.mjs`。修改前阅读项目AGENTS，保留已有数据，先备份。

开发需另装 Node.js 22以上与npm，再在项目目录执行 `npm ci`、`npm test`。自带Python用于运行，若重新安装依赖请按 `requirements.akshare.txt` 建立Windows环境。桌面构建为 `npm run desktop:build`；可移植构建设置 `WUJIAN_DESKTOP_PORTABLE=1`，程序按相对目录找源码，不能写死作者电脑路径。

`scripts/package-share.mjs` 以白名单生成干净分发目录；不复制 `.env`、业务库、操作记录、研究报告、旧打包或登录态。`scripts/finalize-share.mjs` 创建校验清单与ZIP。已保存盘后复盘不改变筛选资格、排序、冻结规则或账户许可。

第三方运行时、依赖和可选参考模块沿用各自许可证，随对应目录保留LICENSE文件。软件未经代码签名；本次仅验证本机Windows独立解压路径，不能代替对方电脑、企业防火墙或付费服务权限的测试。
