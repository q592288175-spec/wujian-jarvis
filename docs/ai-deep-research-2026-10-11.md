# 小木 AI 深度研究（水研究）：方法与使用说明

2026-10-11 Mac·Claude 改版。原因是旧版几乎每次都输出“证据不足”。根因与审查证据见 [对抗审查与冗余清单-2026-10-11.md](对抗审查与冗余清单-2026-10-11.md)。

## 怎么用

火页面勾选品种，或在品种详情里点“进入水研究”，然后点“启动 AI 深度研究”。通常20到60秒出结果，读完约2到3分钟。

页面从上到下：
1. **一句话结论 + 当前阶段（约X成把握）**。阶段从这8个里选：底部构筑、上涨初期、上涨主升、高位震荡、下跌初期、下跌主跌、低位震荡、区间震荡。
2. **合约核对提醒**（只在发现问题时出现）：小木标注的具体主力与东方财富主力不一致，或者该合约结算价与主力连续收盘相差超过3%。
3. **贝叶斯更新**：先验阶段 → 后验阶段，以及变化的原因。
4. **四维证据卡片**：基本面 / 消息面 / 政策面 / 资金面。每张卡写方向（偏多红、偏空绿）、权重，以及带 [E编号] 的要点。
5. **建议**（条件式）与**反转信号**。
6. 采证状态，以及“证据来源”列表，每条可点开原文。
7. 策略结论：技术方向与基本面方向是共振还是冲突。
8. “查看完整研究报告”，Markdown 排版。
9. 四问记录：AI 预填，可修改后点“保存水研究”。注意：当前关联交易卡的研究会自动回填并保存草稿，并非只有点击保存才入库；这是已有行为，手动保存边界尚待单独修复。全品种总表的独立研究只保存研究报告，不写交易卡。

## 工作原理

1. **固定对象**：程序锁定品种、具体合约和盘后完成日K，再加载 `资料包/技能包/wujian-commodity-research` 里该品种的专属框架（定价模型 + 品种画像）。
2. **并行预采集**（`integrations/research-evidence.mjs`，每个来源单独限时、单独失败，失败的列为缺口）：
   - 东方财富资讯搜索：近10天，用品种名、“品种名+期货”、别名各搜一次，按相关度取前14条，前8条读正文；长文只保留提及该品种的段落。
   - 财联社12个公开栏目、金十官方 MCP（需要本机 Token），近7天内按品种名匹配。
   - 交易所仓单：东方财富汇总的全交易所仓单日报，取最近10个交易日。
   - 前20席位持仓：小木具体主力和东方财富主力两份，含多空合计、净多及变化、前5席位。
   - IMA「期货投研」近21天研报标题，只作观点线索。
   - 官方与权威信源直连（`integrations/official-sources.mjs`，2026-10-11 本人要求：借鉴AIHOT期货雷达的信源清单与抓取方法，小木独立运行，不连接Mac）。按品种板块选源：国内有统计局（含旬度《流通领域重要生产资料市场价格》表，按品种提取官方现货价）、发改委、人民银行、农业农村部、上期所公告（只取品种相关和保证金/限额/节假日等通用风控通知）；海外有美联储、BEA、欧洲央行、白宫、EIA、USDA NASS、NOAA；媒体有CNBC、MarketWatch、BBC、OilPrice、FXStreet。英文源按品种英文关键词筛选；官方源没提到该品种时，保留最新1—2条作宏观背景。国内官方条目读详情页中提及品种的段落。列表缓存15分钟，每个来源单独失败、单独列缺口。
   - 东方财富对上期能源、广期所用小写代码，仓单与席位查询同时查大小写。
3. **价格先验**：程序根据完成日K计算日/周/月MA10、20/60/250日区间位置、5/20/60日涨跌、量能比、5日持仓变化和价仓象限，模型不得自造价位。
4. **AI 综合**（DeepSeek，开启思考）：以价格结构为先验，四个维度为似然，给出后验阶段和主观把握。某个维度没取到证据，就写“本次未取得”并降低权重，但仍要给出判断；只有价格数据也缺时才允许“证据不足”。只有某个维度完全空白时，才允许它最多补检2次（`search_latest_news` / `read_news_article`）。
5. 结构化 JSON 回填水页面和交易卡（阶段、四维、建议、反转信号，以及原有四问与策略字段）。原始报告和证据清单另存到 `.runtime/research-reports/`。

## 证据纪律（写在提示词里）

- 事实后面标注 [E编号]；标题或摘要只能写成“据报道/线索”；期货公司观点是观点，不是事实。
- 仓单不等于社会库存，席位榜不等于全市场资金流，持仓增加不等于资金净流入。
- 把握用“约X成”表达，属于主观估计，不是统计概率。
- 研究不给手数、不下单、不构成交易许可。关联卡自动回填仍有覆盖人工草稿的风险，不应把当前实现描述为“默认不保存”；修改人工记录前应保留副本。

## 已知边界

- 东方财富资讯和数据中心是公开免密钥接口，没有服务等级承诺。接口变化时，对应来源会显示“未取得”，不会补造数据。
- 金十需要本机配置官方 MCP Token；IMA 需要本机的 IMA 客户端。
- 现货价格和基差目前没有稳定的免费来源（生意社有反爬验证，没有绕过），由模型从资讯正文中引用。
- 具体主力选法的问题（如甲醇标为MA611，实际价格对应MA701）见审查清单 A1，待五简决定。
