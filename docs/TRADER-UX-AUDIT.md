# 小木交易流程自查 · 2026-09-20

## 产品定位与实施清单
工作台依次解决：选什么 → 看结构 → 触发了吗 → 证据是否足够 → 人工拍板。
首页不把研究结论等同订单，也不以缺失数据填零。

本轮实施：
- 当前筛选结果跨板块涨跌排序，缺失置后，保持选中合约。
- 近期行情显示最新价相对昨收；历史快照显示已完成收盘口径。昨收缺失不使用昨结算替代。
- 压缩图表标题、价格、周期按钮，扩大绘图区，一键放大/Esc退出。
- 补价格网格与日期轴，末根完成状态读取实际标记。
- 红/绿表达方向，强/浅表达月周日或周日共振，同时有箭头和文字。
- 趋势、等待穿越、已穿越仍独立；周日同向不擅自开放月周日触发门。
- 修复窄窗口面板互相压叠，保留独立内容滚动区和底栏。
- 行情过滤、未知、来源时点仍展示，现有研究/语音/账户权限不改变。

## 自查发现及后续边界
- 当前交易计划卡仍是待核验展示，不能称已实现输入止损后的完整风险预算工具。
- 各来源时点不同、产业口径缺口仍需显示；不能声称这次UI修改已修复源覆盖。
- 月周聚合保守排除首尾周期，可能导致最新已完成周期滞后，需交易日历专项验证再调整。
- 资讯中培训、规则公告与行情催化未分层；后续应按所选品种、影响路径、事件时间筛选，不能把标题当驱动证据。
- 缺少成交量副图、十字光标、缩放平移、换月标记，本轮只完成基础K线可读性，不冒充专业完整看盘终端。
- 语音字幕、报告复制、后台任务沿用，不把未测试的真人语音列为通过。
- 不宣称“全软件无bug”；本轮检查聚焦主界面、选品种、收益口径与结构展示。

验证：111项Node测试通过，包含最新价/昨收、空值排序、两周期方向不触发三周期门；原有语法检查通过。
