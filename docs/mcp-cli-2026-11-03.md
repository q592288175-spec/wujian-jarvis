# 小木 MCP + CLI 交付说明（2026-11-03）

## 结论

小木工作台的 REST 接口、页面数据和只读信号已经封装成同一套 MCP Server 与 CLI：

- 代码：`mcp/`
- 使用说明：`mcp/README.md`
- 各 Agent 配置：`mcp/adapters/AGENT-SETUP.md`
- 盘点原始证据：`mcp/.research/api-inventory.json`、`mcp/.research/ui-inventory.json`

不改业务代码、不直接读写 `.runtime` 数据库；所有数据仍通过运行中的 `server.mjs` 获取。

## 一键接入任意 AI

工作台右上角新增 **“复制接入提示词”** 按钮。点一下复制完整提示词，直接粘贴给任意 AI，
它会自动读取路径、写入 MCP 配置、运行自检并按客户端要求重启。提示词源文件是
`dist/agent-onboarding.txt`，CLI 同文输出：

```powershell
node mcp/cli.mjs onboarding
```

## 设计要点

1. **单一事实源**：`mcp/catalog.mjs` 复用 `server.mjs` 路由与 `client.mjs`；CLI 与 MCP 不各自维护接口。
2. **Agent 友好**：默认工具只返回必要字段；K 线、完整席位、证据包按需开启；超限自动裁剪并提示。
3. **权限四层**：read/calc 默认；write、trading、expensive 分别由环境变量或 CLI 参数逐级开启，并要求 `confirm` + `reason`。
4. **可发现**：`wujian_catalog` 支持按分类/权限/关键词查询；`wujian_views` 返回页面深链与按钮映射；`/openapi.json` 给非 MCP Agent。
5. **边界明确**：不生成替代行情、不补造缺失值、不把观察候选当交易许可；服务未启动时直接报错并给出启动命令。

## 未做/边界

- 没有把 MCP 暴露到公网；默认只绑 `127.0.0.1`。
- 没有自动修改用户的 DSH/Claude/Cursor 配置；配置模板放在 `mcp/adapters/`，需用户按各自客户端合并。
- SSE 流（`/api/monitor/stream`、`/api/trend-monitor/stream`、`/api/market-panorama/events`）没有在 MCP 内长期订阅，改为 `wujian_monitor` / `wujian_trend_monitor` 轮询和 `wujian watch`。
- 写/交易/昂贵动作已实现但默认关闭；不会绕过小木的人工批准与审计。
- 部分外部数据（天勤、飞书、火山、DeepSeek）仍取决于本机 `.env` 与账号权限；MCP 只报告实际状态。
