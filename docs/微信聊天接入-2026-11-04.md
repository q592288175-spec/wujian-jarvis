## 怎么使用

在已经绑定的小木微信聊天窗口直接发文字，例如：

- 给我当前工作简报，先检查数据时间，再列候选、待补证据的交易卡和监控异常。
- 查沪铜最新报价，告诉我具体合约和更新时间。
- 把刚才的空头候选单独列出来。
- 读小木已经保存的燃料油研究，列出缺少的证据。
- 今天有点累，陪我聊聊。

不需要记 MCP 工具名或 CLI 命令。可以连续追问；输入“帮助”看示例，输入“新对话”或“清空对话”清除本渠道上下文。微信上下文保留最近20条用户/助手消息，闲置2小时后清空，服务重启也会清空。

支持文字及微信已经转成文字的语音；当前不解析图片、文件和未转写语音。电脑、小木服务及网络需要保持运行。用户本次选择先接通微信，未新建或启用定时简报；已有监控事件推送保持原设置。飞书接入同一查询引擎，但本轮先验收微信，飞书手机问答未验收。

## 查询能力与权限

聊天使用现有 DeepSeek 模型，通过独立 stdio MCP 子进程调用小木本机 API。与 CLI 共用目录及工具实现，可读行情、火机会池、交易卡、账户记录、规则、已有研究、知识库及监控状态；纯计算同样可用。大结果分批查询，截断会明确标示。不能据此宣称工作台所有文件或所有数据已完整读取。

- 42个只读/纯计算工具可见。写入、交易、昂贵动作开关均为0；不会以 MCP 启动研究、刷新、修改业务记录或批准/执行交易。
- 普通问答使用已有模型配置，不转发模型密钥到 MCP 子进程；没有新增第三方模型供应商。
- 微信只处理扫码绑定者的消息，拒绝其他人、群聊、过期及生成中的消息；换绑后取消旧会话结果。
- 消息去重记录只保存哈希标识及处理状态，不保存聊天正文；发送结果不明时不自动重发。
- 凭据沿用既有本机加密绑定，未读取、输出或复制凭据文件；模型工具结果按敏感字段过滤。
