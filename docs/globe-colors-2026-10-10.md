## 当前行为

旧球面根据语音状态变色：空闲蓝色、接通中偏紫、播报中偏绿，不代表市场涨跌或板块。本轮将全息地球与语音配色解耦；只修改视觉导航，不修改火筛选、账户、交易、提醒或复盘规则。

| 板块 | 地球颜色 |
| --- | --- |
| 股指/国债 | 红色 `#ff5f67` |
| 贵金属 | 橙色 `#ff9f43` |

| 新能源金属 | 绿色 `#4bd98c` |

| 能源化工 | 蓝色 `#548dff` |

| 航运 | 保留切换前的地球配色，不新增第八种颜色 |
| 全部板块 | 七彩环绕、平滑流动 |

球面、大气层、经纬网、轨道及底部环使用同一配色；全部板块七色闭环约56秒，球面继续缓慢旋转。板块按钮增加对应小色标及悬停名称，候选与计数仍沿用多红空绿，板块色不表示交易方向。

开启系统减少动画后，七彩保留，但自动旋转与颜色流动停止；点击板块仍切色，手工拖动仍有效。隐藏页面暂停绘制，恢复后不快速补播动画。
