# 小木市场全景：九页检查与修改方案

状态：五简已于2026-10-24确认，现已实施并验收；另按追加要求更新四页两排选择器。以下保留原计划，完成情况见 [实施与验收](market-panorama-clarity-acceptance-2026-10-24.html)。

## 这次要做到什么

以已经改好的“资金排行”为清晰度基准，把资金动向、持仓动向及其余市场全景页面的文字、数字、标签统一清楚。保留左侧九页导航、各页主要模块的位置、原有功能和操作路径。改善目的是更容易读、比较和找到依据。

本轮不调整 MA10、多周期判定、强弱评分、火筛选、金计划、账户和风险规则；不重设计全息工作台。资金、持仓页保留上方选择、下方图表和明细的原顺序。不会把选项直接删掉或默认藏起来，也不把全部内容强挤进一屏。

## 检查依据与边界

1. 检查当前项目源码，用本机市场 SQLite 的一致性备份搭建临时审查服务。正式 4318 服务当时没有运行，没有替用户启动正式业务服务。
2. 逐一打开九页，在 1920×1080、1440×900 两种尺寸截取真实页面；检查主界面、关键表格、图表和计算后的样式。截图都来自本轮，未用旧截图代替现状。
3. 抽查资金按席位/按商品、持仓四个标签、席位动向五类过滤及空名单。九页没有捕获到页面脚本异常，两种尺寸没有整页横向溢出；手续费在较窄窗口存在表格内部横向滚动。
4. 当前缓存覆盖 87 个品种，82 个有价格、72 个有席位样本。主要日K及席位日期为 2026-10-23，部分最新报价日期为 2026-10-24。未执行新的外部行情采集，不能把本次检查说成行情源完整性验收。
5. 产品脚本、HTML、两份样式表检查前后哈希一致；未写业务数据库、账户、自选、交易计划或用户窗口状态。只新增审查文件和文档。

## 核心发现

- **最浅的是辅助文字与标签，不是所有数字都不合格。** 旧板块标签为 10px，文字对背景对比度约 2.81:1；一般表头约 3.68:1，周期板块分布表头约 2.80:1。现有资金排行表头约 6.50:1，板块标签明显更清楚。一般红绿数字测得约 4.86:1、5.04:1，但许多页面只有 12px、常规字重，远看仍显细。
- **关键图表被选择项推到下面。** 甲醇示例有 87 个品种按钮、53 个席位按钮。1440×900 下，资金曲线约从第 784px 开始，持仓页价格图从第 655px 开始、持仓图从第 1279px 开始。首先通过减少重复说明、无效上下空白改善；模块顺序和选项保留。
- **存在实际显示问题，不能只换颜色。** 实测选中 13 个席位，资金图仍只有 12 条线；代码有无提示的 `slice(0,12)`。总览“品种强弱”先取涨幅前列，再被通用表格重排为板块顺序，出现 +4.86% 排在 +6.01% 前面。
- **部分“数据不足”与名称匹配有关。** 直接调用当前函数，“中信期货”匹配机构观察组，“中信期货（代客）”返回空；国泰君安、永安期货也一样。当前席位动向 72 个样本中有 69 个归为不足，这个数字不能全归因于名称问题：还包含真正缺少可比组别/双侧数据的情况。
- **同一个板块跨页叫法不一致。** 品种强弱已拆能源、化工，部分筛选和标签仍合并为能源化工。修正显示归类后，应让标签、筛选和数量一致，不能只改字。

上述对比度是本轮抽样的实际计算结果，不代表已做完整无障碍认证。

## 统一的显示标准

| 项目 | 拟采用标准 |
|---|---|
| 字体 | 保持现有微软雅黑等系统字体；主要表格13–14px、辅助文字至少12px；关键数值600–700字重。标题保持现有层级，不把整页全部加粗 |
| 表格 | 数据表采用资金排行的深蓝表头与白字；普通数值靠右/等宽数字，单位放表头；单行约38–42px，有合约副行允许更高；保留清晰分隔，不新增装饰边框 |
| 红绿数字 | 统一深红 `#C62F24`、深绿 `#286C50` 为目标，按实际背景验收；正负号和数值保留。0为中性，缺失明确“未取得/待核”，不靠颜色区分缺失 |
| 状态色块 | 强/弱仍红绿；偏强/偏弱用浅底＋深色字，重要文字对背景目标至少4.5:1；“平衡”和“不足”不合并文字 |
| 板块 | 固定顺序：股指、国债、贵金属、有色、新能源、黑色系、能源、化工、农产品、农副产品、其他；沿用品种强弱已确认的展示归属。相同板块各页同名同色；展示统计、筛选和标签一起核对，不改后台交易板块规则 |
| 图表 | 坐标、图例12–13px深灰蓝；线条适度加粗、同一品种/席位颜色固定，不能12条线只循环8种颜色又无区分；必要时辅以线型。曲线颜色用于识别对象，红绿数值用于正负，不将曲线颜色解释成资金方向 |
| 当前选择 | 仍用现有选中/焦点提示。板块颜色放标签与轻背景，不给每块内容加彩色边框，避免与用户点击选中混淆 |
| 时间与数量 | 数据日期、最后读取时间分开；说明具体图表的日期范围、席位样本和已绘数量；保留原始数据来源与限制，减少各页无关的重复长提示 |

## 同步修正的三处显示/识别问题

1. **排序不能在最后一步被改掉。** 总览的当日涨幅榜和“重点变化”应保留各自指标排序；普通品种浏览仍按固定板块顺序。不同表头的排序状态分开，点击一个表格不应顺带改变另一个排行的含义；并移除重复表格ID带来的定位歧义。
2. **选择13个不能无声只画12个。** 默认12条的行为先明确写出显示数量；用户明确选择的席位须完整绘出，确有性能限制时清楚分批并提供翻看，不静默丢失。合计图和明细使用同一筛选范围；缺失仍断线，不补零。
3. **同机构名称后缀的识别。** 为已验证的官方名称建立精确标准名映射，例如“中信期货（代客）”识别其机构名，同时保留完整原名和代客/自营属性。只对既有观察组名单做身份匹配，不增加成员、不模糊猜测、不合并原始持仓行。变更前后对比各组样本数量，仍无数据的必须保留“不足”。

这三项属于修复显示与匹配问题，不是新增交易条件。名称匹配会使部分观察组统计数量发生合理变化，因此必须在验收中单独列出，不能当作纯换色悄悄发布。

## 不纳入本轮的布局改造

资金、持仓页的选择项确实占空间，但用户明确要求保留布局。因此本轮只调整字号、标签、间距、提示与明细，不默认折叠品种或席位，不把价格图和持仓图重排成左右双栏，也不删减周期卡或自选功能。品种强弱当前展示约六年日K对比，是否默认缩短为近期属于另一个体验选择，本轮保留现状。

## 确认后的实施顺序与验收

1. 先保存当前源码与样式恢复点，记录本轮数据快照、页面截图及现有行为。
2. 先做资金动向、持仓动向，复用资金排行已验证的清晰样式；再统一其余七页的文字、标签、数值和图表规范。
3. 单独修复并测试排序、13席位完整显示和精确名称匹配，记录影响。样式层收敛到市场全景组件，避免影响稳定版、全息版或账户页面。
4. 用1920×1080、1440×900、1366×768检查，另做125%缩放；不以缩小字体换取塞满。长表首行/品种定位、选择、日期、搜索、排序、空结果与错误提示均需可用。
5. 字体和颜色逐类量测；做正常、部分缺失、平衡、正负/零值、多选、无候选验收。九页真实点击；资金按席位/合计、持仓四个标签、强弱全选、周期联动、费用平今/平昨、详情导航逐项回归。纯视觉改动不应改变任何数据值；名称映射变化须单独对账。
6. 通过语法和针对性测试后重建桌面包，在独立测试窗口启动验收，保留用户正在使用的窗口。交付前后截图、测试结果、实际覆盖和未完成项。

本段为提出方案时的验证边界。当前开发及桌面验收已完成，详细证据见实施报告；外部数据刷新和完整无障碍认证不属于本轮验收。
