## 旧版记录
以下为升级前的二进制/Ogg方案记录，不作为当前配置指引。

在设置中选择“火山实时语音”，打开通话面板点击“接通语音”，首次允许麦克风。说出品种和任务，例如“查询沪铜最新行情”或“深入研究沪铜”。停止播报和挂断不会取消已启动的研究任务。

服务端 .env 使用 VOLC_VOICE_API_KEY（新版控制台 API Key），同时需要 DEEPSEEK_API_KEY。APP ID 可保留在本机配置，新版鉴权请求仅使用 X-Api-Key。长期密钥不下发前端，浏览器使用一次性30秒连接凭证。

链路：16kHz PCM → 火山 ASR → DeepSeek 与真实数据工具 → 火山 ChatTTSText → Ogg 分句播放。仅播放外部文本合成的声音，过滤语音模型自发回答。麦克风在播报及工具工作时保持采集，检测用户开口时停止旧音频。研究完成后可在通话中提醒，报告保存在工作台。

2026-09-19 验证：真实服务鉴权、合成测试音频识别、DeepSeek行情工具回答、返回可识别为 Ogg 的音频均通过。66项自动测试通过，包括协议、一次性凭证和44.1/48kHz重采样时序。尚未完成真人麦克风、扬声器回声与插话延迟试听；不能将此测试视为真人全双工体验验收。测试“沪铜”曾误识别为“户头”，选择当前合约可辅助消歧。

每次通话上限15分钟，断线需要重新接通。播报需等待 DeepSeek 回答与音频分句完成；未承诺固定低延迟。服务端重启可能中断未完成研究，挂断语音本身不会。
