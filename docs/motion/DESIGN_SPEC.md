# 五行声核 · 设计规范 V1

## 视觉主张

不是把金融工作台变成霓虹游戏大厅，而是让“静止时可靠、开口时有生命感”成为五简的识别。
唯一主视觉为五行环印 / 声核。五个弧形构件收束成同一个环，不拼五个具象金木水火土图标。不把上涨箭头或收益曲线当承诺。
主 Logo 和声核中央标志使用同一套几何，主界面仅一处高亮视觉中心。SVG 为可编辑路径，标志不依赖字体。

## 色彩

- 背景 #050D18、面板 #0A1623、高层 #101F2E、分隔线 #243746。
- 正文 #E5EDF4、次要文字 #8FA5B6、核心 #76E4DF。
- 金 #D6BD7A；木 #88B6A2；水 #78BADC；火 #DB927F；土 #B7A18A。

上述五行色只表示职能。实际报价涨跌保留原应用的规则和图例，禁止因为品牌色改变金融语义。
背景网格、轨道只有微弱层次，表格和K线后不堆复杂高光。展示图中的细小坐标注记是装饰；生产业务正文建议至少 13–14px，辅助文案至少 11–12px，按真机分辨率校准。

## 图标

24×24 viewBox、1.6px 线宽、round linecap/linejoin。资源名即职能，24 个图标 + 一个 sprite。16px 时单独检查细节，20–24px 为建议 UI 尺寸。头像/应用图标用 app-icon，不要硬把细线小图标放大当 Logo。

## 动效语法（目标值，不是测试测量）

| 状态 | 视觉 | 声音关联 |
|---|---|---|
| 未接通 / 待机 | 4.6s 缓慢呼吸，约 0.97–1.025 倍 | 仅装饰，明确未接通 |
| 连接中 | 一段低亮金色弧线缓慢旋转 | 不伪造正在听 |
| 已接通静音段 | 保留低幅呼吸，无随机波形 | 电平低于噪声门时静止 |
| 用户输入 | 蓝色外环细涟漪 | 实际输入样本 / RMS |
| 工具处理中 | 低亮金弧，不假装播报 | 用真实工作事件，麦克风仍可用 |
| 助手播报 | 青白内环与内核轻扩张 | 实际播放图样本 / RMS |
| 双向音频 | 内外环独立 | 两个 tap，不用一条假的总波形 |
| 断线/拒绝权限 | 文字说明 + 静态状态点 | 不显示在线或监听状态 |

输入输出采用 45ms attack、220ms release 平滑目标，输出核最大额外放大约9%。数值只是初始设计参数，需真人试音调门限。背景噪声不是 VAD。
按钮 hover/press 160ms；抽屉入场建议 240–320ms，优先 transform/opacity。避免每帧全屏 blur、backdrop-filter 和大粒子喷射。
核心模块默认每秒最多约30次计算/绘制，两个核心复用一次循环；降低动效时不变形不旋转，保留文字状态。页面不可见暂停渲染，绝不停止通话或后台任务。

## 资产目录

- `assets/brand/`：青白主标志、单色标志、待机呼吸 SVG、方形 App 图标；附 1024px PNG 导出。
- `assets/icons/`：24 个独立 SVG，sprite.svg 与 manifest.json。
- `assets/backgrounds/`：低对比网格氛围、透明地平线、透明面板角标。
- `runtime/`：CSS token、只读音频采样器、纯数学函数、双核视图。

`wujian-mark-breathe.svg` 是纯装饰循环，不负责声音。真正声音联动在 runtime，不可用前者替代后者。
本包未做商标近似检索；品牌投入正式发布前保留人工复核。
