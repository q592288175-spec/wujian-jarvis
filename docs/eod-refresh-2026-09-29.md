# 小木15:30盘后刷新验收

2026-09-29在Windows APP内点击“刷新盘后数据”验收。以刷新完成后的逐品种交易日期为准。

## 数据路径

1. 新浪具体合约历史日K提供历史序列。
2. 交易所日行情优先补齐目标交易日开高低收、成交量及持仓量。
3. 正式日表尚未取得时，使用新浪带合约代码和日期的盘后快照，明确标为“待正式复核”。普通合约报价时间须达到15:00，国债须达到15:15；不能使用夜盘、前一日或未来时间的报价。
4. 同合约同日去重，正式日表优先于快照。原始响应、具体合约缓存及历次扫描都保存在 `.runtime/fire-scan`。
5. 火筛选和详情图读取同一具体合约缓存。缺目标日数据不进入候选；交易所确认零成交、零持仓的品种单列。

免费公开接口没有15:30全量必达承诺。此实现支持15:30后主动刷新并明确覆盖率，不能把免费源未返回的内容视为已同步。再次点击刷新会补充当日已发布的正式日表。
