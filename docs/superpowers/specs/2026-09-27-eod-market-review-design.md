# 小木免费盘后行情复盘设计

## 目标

小木默认使用免费盘后数据，支持每日收盘后查看国内期货完成日K及由其聚合的完成周K、月K。系统不依赖天勤账号，不追求盘中实时，不提供历史逐日回放或自动交易。

## 数据口径

- 长期序列：AKShare `futures_zh_daily_sina` 的品种主力连续日频数据。
- 当日具体主力：AKShare `get_futures_daily` 读取交易所公开日线，按成交量与持仓量共同确认当前具体主力，只作当日合约标识与交叉核验。
- 展示与计算：只使用完成日K；涨跌幅按相邻完成日K收盘计算；周K、月K由完成日K按自然周期聚合。
- 换月边界：主力连续用于长期结构，具体主力单独显示。两者不伪装成同一条无换月影响的实际合约序列。

## 数据流

1. Node 服务启动后触发一次盘后刷新。
2. Python 采集器读取免费公开数据，写入本地 SQLite，并原子生成 `.runtime/market.json`。
3. 现有 `/api/live-market` 保持兼容，但返回 `eod-ready` 盘后状态与全部完成K线。
4. 首页、数据来源页和研究工具统一读取同一份盘后快照。
5. 用户可手动触发刷新；服务在上海时间收盘后每天最多自动刷新一次。

## 界面行为

- 首页状态显示“免费盘后数据”，不再显示“实时订阅”或“等待天勤”。
- 日K末根明确标记为已完成；保留日K、周K、月K和 MA10。
- 移除分时入口以及依赖盘中最新价的提示。
- 显示数据日期、连续序列来源、当前具体主力、采集时间和失败数量。

## 错误处理

- 网络刷新失败时保留最近一次成功缓存，并明确显示缓存日期。
- 某品种失败只记录缺口，不用演示数据补齐。
- 没有缓存时显示不可用，不把零值当行情。
- 账号、手机号、密码不进入配置、日志或数据文件。

## 验收

- 至少一个国内期货品种取得多年真实日K。
- 最新两根完成日K可计算收盘涨跌，周K和月K可聚合。
- API 返回 `eod-ready`、明确来源、完成K线和当前具体主力字段。
- APP 首页可查看盘后品种列表和K线，不启动 TqSdk。
- Node测试、Python测试、语法检查和浏览器验收通过。
