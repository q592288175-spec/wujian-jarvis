# 五层环境自动计算

2026-10-02。用户明确要求自动获取并填写五层方向、判定证据及真实刷新时间，默认日K十均线；主周期周线时大盘和板块用周MA10，小周期入场仍使用日MA10背景。

## 方向规则

各周期当前MA10大于前一根MA10为多头，小于为为空头，严格相等为中性。缺数据、合约不匹配或行情未覆盖本次截止日期显示未知。本项只判均线方向，不加入价格位置、结构、新闻或额外阈值。

- 新计划主周期默认日线；大盘与板块对应日MA10。
- 主周期选周线，大盘与板块对应周MA10。
- 主周期选小周期，大盘与板块仍对应日MA10。
- 品种月线、周线、日线始终分别呈现自身周期的MA10。
- 当前动态周月线使用截至最新完成日K的周期收盘，不等待周末或月末才更新。
- 方向是量化环境记录；批准和各项账户风险仍执行既有规则。

## 数据来源

品种层直接复用最新火扫描的当前具体合约MA10与前值。必须与交易卡合约一致，换月后不能将新主力均线套给旧合约卡。

文华官方介绍页：[文华商品指数](https://www.wenhua.com.cn/Home/WenhuaIndex)。本次没有取得公开、可用的文华历史日线接口，当前大盘使用“中证商品期货价格指数（文华替代）”，代码 `000001.CCI`。数据通过中证商品指数公司的公开日线接口读取，按日期排序、使用收盘点位，明确保留真实来源及抓取时间。接口参考：[AKShare 中证商品指数实现](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_index_ccidx.py)。

该指数与文华的构成和算法不同，不显示为文华数据。股指/国债不使用商品指数作为大盘证据，金融基准尚未接入时保留未知。

板块使用“小木板块等权参考指数（非文华）”。成分来自现有八类展示分类；每个成分采用扫描保存的具体主力日线，截至同一行情日期。以共同历史起始日期归一化到1000点，随后等权平均，再由合成收盘序列计算日或周MA10。高名义价格品种不会仅因价格高而获得更大权重。

只采用至少11个完成日K且覆盖截止日期的成分；对共同交易日期取交集。样本不足显示未知。缺失成分不补零，每次显示实际覆盖和缺失品种。这个结果代表可取得样本的等权参考，不冒充完整板块官方指数。

## 更新与时间

打开金页面、切换主周期或点击刷新环境时自动获取证据。火盘后扫描成功后补抓大盘指数；指数缓存超过30分钟时尝试更新，失败保留旧缓存与旧时间，不能用当前时间冒充抓取成功。

品种与板块证据时间采用扫描数据真实刷新时间；大盘时间采用指数实际抓取时间。另存本次计算时间，两者不混用。页面时间统一显示北京时间到分钟；来源栏单独标出行情日期。

休市期间行情截止保持最后交易日。指数最新行情早于火截止时，大盘方向为未知，不能用陈旧均线获得环境许可。读取新版报告会按当前卡合约重新计算；历史冻结版本保留自身快照。

## 计划证据

五层方向、依据与时间由程序填写，页面只读。风险测算使用服务器重新计算的环境；冻结时保存五层快照和哈希。哈希包含方向、均线前后值、合约或指数标的、周期、日期、来源与板块成分，不因重复读取时间而改变。

批准前再次计算，证据变化或旧计划没有自动环境哈希时，要求重新测算并冻结。旧版本不因新的环境计算被批准；人工账户资料和入场止损仍需核对。
