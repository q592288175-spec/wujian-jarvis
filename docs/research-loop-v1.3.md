# 品种研究闭环 v1.3

2026-09-19，验证中。默认仍使用稳定版。

## 目标与验收

输入研究池品种 → 冻结真实行情与完成日K → 查询官方证据 → 生成九部分报告 → 保存 → 下次关联同品种旧报告并审计。量仓均须严格超过10000手；报价时间、交易日、采集时间分开显示。

新增：全量历史中查找同品种上一份完成报告，不受最近30份展示限制；合约换月保留关联但禁止直接比较不同合约价格与持仓。保存工具检索及原文结果，自动检查报告章节与引用链接是否来自工具记录。检查通过不代表事实准确，报告仍待人工核验。

服务中断后的运行记录显示失败和重新发起提示，避免永久“进行中”。已完成报告不覆盖。旧版报告兼容读取，但不伪造旧版没有保存的证据。

## 运行与回滚

正常 npm start，进入稳定版“深度研究”。报告及证据存 .runtime/research-reports，禁止提交公开仓库。改动前源码备份 .runtime/checkpoints/before-research-loop.tar.gz，包含本轮改动前源码、不含.env与账户资料。需要回滚时先停止服务、备份当前源码，再解压该包覆盖源码并启动。该备份仅回滚本轮源码，不删除研究记录。

## 边界

官方搜索可能无结果；此时模型必须列缺口，不能编造事实。当前只做结构与来源轨迹审计，不自动判定历史情景已触发，不生成概率后验或订单。全球持续采集、全双工语音与桌面封装为后续阶段。
