# 天勤账号登录接入

市场全景及全息版顶部新增“行情连接”。在本机页面输入快期 / 天勤账号、密码，点击“登录并连接行情”，查看鉴权结果、心跳、订阅数、实际报价与时间。使用快期服务账号，不使用券商资金账号，也不另外生成 API Key。

## 已实现

- 浏览器和 Windows APP 使用同一连接；未配置提醒或尚无火扫描名单，也能从天勤主力目录订阅行情。主力目录更新时补充同品种的新合约。
- Windows 可加密记住账号，重启后恢复；未勾选则只保留当前进程会话。
- 密码不进入命令参数、页面存储、状态接口、报价接口或导出资料。旧桌面密文可兼容导入，退出新连接后不会被旧文件重新自动登录。
- 报价通过同一只读采集进程进入市场全景：最新价、相对昨结涨跌幅、成交量、持仓量。只有同日、同合约、有效时间戳才能使用；历史查看和主力换月不会混用。
- 已有盯盘提醒的规则及启停状态保持。原先暂停监控时，登录取行情也不会恢复提醒。登录不会创建新提醒、交易卡或委托；现有提醒共享行情连接。
- 账号密码或权限未通过、SDK运行库缺失、网络中断分别显示；提交登录请求不等于认证成功。
- 历史K线、席位、基本面等继续保留各自来源，没有因为天勤登录而统一改名。

## 验证和边界

51项聚焦测试通过，包含 Windows 当前用户 DPAPI 实际加解密、退出清除、恢复连接、报价合约和日期隔离、现有提醒与市场回归。另有3项 Python 时段与合约映射测试通过。

浏览器及重新构建的 Windows APP 已实际启动；通过隔离 SDK 驱动真实 Python 采集器验证登录、量价仓进入市场全景、错误凭据、跨站拒绝、密码清空、全息入口与文字颜色对比。截图与结果：`output/redesign-2026-10-25/tq-login-20261028/`。隔离 SDK 不访问外网，不验证真实账户权限。实际 TqSdk 3.10.2 在本机可导入。

真实账号由本人在本机输入，目前未进行本人天勤账号的外网认证，不承诺所有交易所实时权限或固定8000根免费历史。测试数据没有写入正式行情库、交易卡或账户。

## 启用

新版构建：`.runtime/desktop-tq-login-20261028/小木-win32-x64/小木.exe`。

桌面与开始菜单快捷方式指向本构建；当前打开的旧窗口保留，避免丢失未保存编辑。请先保存编辑，通过“小木 → 退出”完全退出，再从桌面快捷方式打开。仅刷新网页不能加载新增后端接口。

源码备份：`output/tq-login-20261028/before/`。业务数据库的前后清单及快捷方式原目标同存在该输出目录，旧构建保留。

官方依据：[快期服务账号认证](https://doc.shinnytech.com/tqsdk/latest/usage/trade.html)、[TqApi接口](https://doc.shinnytech.com/tqsdk/latest/reference/tqsdk.api.html)。
