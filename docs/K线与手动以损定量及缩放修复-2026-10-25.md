# K线、手动以损定量与页面缩放

2026-10-25。三项修复已完成，新桌面程序已构建并在隔离业务副本中实际启动验收。

## 现在的操作方式

1. 详情K线采用红色空心阳线、绿色实心阴线和蓝色MA10。火的详情、金的分析图及市场全景的K线采用相同的颜色含义，K线数据和MA10算法不变。
2. 金的四种手法下方恢复“以损定量”。选择试算账户，手动填入或修改计划入场价、止损保护价及亏损比例，即时显示可承受亏损、止损距离、每手止损金额和向下取整后的手数。
3. 系统建议仅用于预填。已手填的价格不会被后续分析覆盖；点击“采用最新建议价格”才主动改用建议值。确认手法后仍可看见四种手法和试算区，价格与下方审定双向同步。原有实际参与账户勾选、累计风险、结构确认、价格最小变动及最终拍板检查继续生效。
4. 桌面端支持 Ctrl＋鼠标滚轮缩放整个页面；Ctrl＋加号放大、Ctrl＋减号缩小、Ctrl＋0恢复100%。工作台菜单也有“放大、缩小、恢复100%”。比例范围50%—200%，刷新和切换到全息版会保留比例。

**启用桌面缩放：先保存当前未保存的内容，再通过“小木 → 退出”完全退出，重新打开原来的桌面“小木交易工作台”图标。只关闭窗口可能保留后台进程。** 现有桌面窗口没有被强制退出。

试算公式沿用原实现：

`可承受亏损金额 = 实际账户余额 × 亏损比例`

`每手止损金额 = |入场价 − 止损价| × 该品种每点每手金额`

`价差测算手数 = 向下取整（可承受亏损金额 ÷ 每手止损金额）`

本次没有改预算及审批规则。试算手数是按止损价差算出的上限，最终审定继续检查本轮已用预算、已有风险占用及账户限制。试算和编辑不会自动批准或发出交易委托。
