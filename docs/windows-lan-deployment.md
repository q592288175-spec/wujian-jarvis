# 小木：Windows完整迁移与局域网部署

适用：Windows 10/11 64位。完整版迁移包由原机持有人私下保管，包含账户、历史、行情、API配置和运行组件。GitHub只存放可公开的源码，不包含这些私人资料。

## 另一台电脑使用

1. 将ZIP完整解压，推荐解压到 `D:\五简个人资料\2026年10月文件`，使程序仍位于 `小木工作台\wujian-jarvis`。路径中可以有中文；不要直接在ZIP里运行。
2. 双击顶层的 `1_启动小木.cmd`。已附带Node、Python、依赖和Windows桌面程序，无须另装开发环境。
3. 首次启动会把随包迁移的语音、微信、飞书等凭据重新加密到当前Windows用户，并修正运行路径。它不会输出密钥，也不会改交易规则或替你批准方案。
4. 替换主机时，先退出旧电脑的小木，再在新电脑使用，避免两个客户端竞争微信会话或重复通知。第三方平台若要求重新登录，请在小木中重新扫码或授权。

账号余额和历史是制作迁移包时的快照，两台独立桌面之间不会自动双向同步。希望所有设备看到同一份最新数据，应选定一台主机，其余设备都访问该主机的局域网页面。

历史证据及已审定方案可能记录原绝对路径。推荐保持原路径；换目录启动已做便携化处理，但历史引用须按实际情况核验，不会批量改写冻结方案或沿用旧批准。

## 手机、平板和其他电脑访问

1. 主机双击 `1_启动小木.cmd` 并保持小木运行。
2. 首次使用双击 `3_允许局域网访问（管理员）.cmd`，在Windows提示中允许。规则只开放TCP 4321，来源仅限本地子网。
3. 双击 `2_启动局域网访问.cmd`，保留该窗口。窗口会显示当前主机的网址，如 `http://192.168.1.10:4321`。
4. 同一路由器下的其他设备在浏览器中打开该网址，输入 `局域网访问口令.txt` 内的口令。口令在程序目录保存，不写在公开文档或GitHub中。

局域网页面共用主机上的业务库和账户，也具有相同业务操作权限，适合本人和可信团队使用。没有另建试用账户隔离。主机休眠、退出小木或关闭局域网窗口后服务不可用；更换网络后按窗口显示的新IP访问。访客Wi-Fi、AP隔离、VPN或企业策略可能阻止互访。

当前入口采用HTTP，只用于可信局域网，不做路由器公网端口映射。浏览器远程麦克风通常要求HTTPS，局域网HTTP不能保证语音通话；可使用主机桌面语音，需要远程语音时另配可信HTTPS。网页行情、研究、计划等原有功能继续由主机服务提供。

## 日常维护

- 关闭局域网：在局域网窗口按Ctrl+C。业务服务仍保留本机127.0.0.1访问。
- 口令位置：`小木工作台\wujian-jarvis\局域网访问口令.txt`。对应认证文件为 `.runtime\private\lan-access.json`，保存散列，不在页面暴露。
- 忘记口令：停止局域网服务，将上述两个文件备份并移开，再次启动会生成新口令。现有浏览器会话同时失效。
- 备份：退出小木后备份整个解压目录；切勿把两台电脑的数据库直接覆盖合并。
- 完整ZIP含可恢复的API凭据和账户资料，只应交给本人持有。公开分享试用需要单独的空账户、独立配置和隔离部署，不能直接发布这个包。

仓库： https://github.com/q592288175-spec/wujian-jarvis 。克隆源码不等于完整迁移，源码不带私人数据库、密钥、资料包和运行组件。开发机安装符合package.json要求的Node后运行 `npm ci`、`npm test`、`npm start`；行情与语音等按各自配置启用。局域网入口用 `node --env-file-if-exists=.env scripts/start-lan.mjs`。
