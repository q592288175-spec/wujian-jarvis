# v0.4.3 共振优先级、分时与产业证据

起始 HEAD 0733e18，工作区干净。源码检查点 .runtime/checkpoints/20260920-100512-source.tar.gz；没有回退已有版本，没有修改密钥。

## 已实施
- 机会证据：月周日均上行或均下行同侧为金色；仅周日同侧为橘色。分歧、走平、历史不足不冒充同向。
- TqSdk quote.average 原始当日均价；quote.last_price 与均价均带原始时间和交易日。行情结构新增分时按钮，仅绘制采集器本次连接观察到的点，不倒造全天均价。
- 三周期同向：多头在线下等待上穿，空头在线上等待下穿。实际观察到跨越才提醒。首条、断连超过15秒、缺失、换交易日不推断穿越；历史报价不提醒。选中合约弹出提示，同一事件页面内去重。无后台推送、无自动交易。
- 小木文字/语音共用Agent及后台研究增加产业证据包、EDB指标搜索和数值查询工具。按品种板块访问交易所、统计局、农业农村部、USDA/EIA及美联储入口，按相关标题读取正文和HTML表格，15分钟内存缓存，显式缺口。入口页不当文章；观测日、发布日期必须核对，抓取时间不是数据日期。
- 官方白名单扩大至农业/商务/马来西亚棕榈油局/巴西CONAB，仍禁止任意URL、用户信息URL、非HTTPS和越界重定向。
