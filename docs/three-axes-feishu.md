# 三板斧参考研究与飞书 Agent

版本：2026-09-19，验证中。

## 研究模块

参考仓库 https://github.com/rfdiosuao/three-axes-futures-toolkit ，固定提交 `3ceeb2ad1e7d40f3cd779867859130ac56e0de19`，MIT 许可保存在 `vendor/three-axes-futures-toolkit/LICENSE`。保留原筛选脚本供溯源，不运行它的入口。

接入范围：月/周/日 MA10 共振、ATR14 参考止损、价仓变化、八段式复盘、显式参数风险手数计算，以及飞书问答和定时报告。数据统一读取本项目 TqSdk 实际月份合约，只处理完成K线；量和仓必须同时大于一万手。收盘变化使用前收，不使用前结算。

未采用原项目的500万元模拟权益、默认账户风险比例、合约乘数回退和黄金结算价口径。共振与1.5倍ATR属于外部参考方法，不代替五简正式规则或五道门，不发放交易许可。账户未接入时，权益、仓位和手数保持未知。历史不足时不产生共振结论。

“火·机会雷达”可查看报告；Agent 可调用 `get_three_axes_report`。接口：`GET /api/three-axes`；`POST /api/three-axes/size` 需要明确传入 equity、riskPct、exposurePct、entry、stop、multiplier，没有默认资金。后者只计算手工参数，不查询账户。

## 飞书配置

采用飞书官方 Node SDK 1.74.0 长连接。本地无需公网域名或入站端口。官方说明：https://github.com/larksuite/node-sdk/blob/main/README.zh.md 。

1. 在飞书开放平台创建企业自建应用，添加机器人能力。
2. 为应用申请接收私聊消息、以机器人身份发送消息的权限。群聊需要接收群内@机器人消息的权限；在平台控制台根据订阅事件提示配置权限。
3. 事件订阅采用长连接模式，添加 `im.message.receive_v1`。配置可用范围并发布应用版本。
4. 在本机双击 `配置飞书机器人.command`，填写 App ID、隐藏输入 App Secret、允许访问者的 Open ID 和推送目标。Open ID 必须属于该应用；不要使用其他应用获取的 ID。群聊还需 Chat ID 和机器人 Open ID。
5. 重启工作台，在“数据来源 → 飞书 Agent 与定时报告”查看连接状态。先预览报告，再按“立即发送”验证授权和接收目标。
6. 真实收发通过后，勾选启用定时推送并保存。默认关闭，推荐北京时间15:30、21:00，可设置每天1—4个时刻。

凭据只进入权限600的本地 `.env`，Git忽略，不进入前端或状态接口。用户白名单不可为空；群聊必须同时在白名单且@机器人。非白名单、旧消息、机器人自己的消息不回应。不得把群机器人 webhook 密钥当作此应用的 App Secret。

可说“日报”“研究沪铜”“查询原油行情”“查看研究任务”。研究由现有 DeepSeek Agent 执行，长任务完成后通知原请求者；关闭网页不会取消后台任务。

## 定时与可靠性

- 本机工作台、网络和行情采集必须持续运行；不是云端24小时服务。
- 只有 TqSdk 已确认的交易日期才推送，日历超过14天即停止定时。采集器启动时刷新日历；长期运行需要定期重启采集器刷新。
- 每30秒检查一次，只有计划时刻之后5分钟内执行，关机或睡眠错过不补发。
- 先持久化事件和发送记录，再调用飞书；重启后已发送不重复发送。结果不明时不自动重试，需人工核对。
- 行情未就绪时，定时仅发送采集异常提示，不包装正式日报。真实行情报告也不意味着所有产业数据已覆盖。
- 报告与去重记录位于 `.runtime/feishu/`，不提交GitHub。飞书长文本会截短，完整报告保存在本机。
- 当前未接入原项目的云文档、多维表格、PandaAI账户或自动下单。没有飞书凭据时，只能验证本地预览和拒绝未配置推送，不能声称真实消息已送达。
