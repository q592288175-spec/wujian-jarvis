# 市场按钮选中与火周期切换修复

已完成两项修复，当前窗口按 Ctrl+R 刷新生效。

## 看市场：统一选中状态

九个市场页面的板块、品种、类型、观察组和排列按钮共用一套选中样式：蓝底白字，未选中为浅底深字；鼠标悬停为浅蓝提示，键盘焦点为蓝色轮廓。

原有样式按页面反复覆盖，部分选中按钮的字色与底色接近。新增统一样式入口，明确按钮及其内部名称、代码、计数的字色，修复资金排行“席位持仓变化”和“全部席位”选中后文字不清楚的问题。涨跌数值仍使用红绿，未改变分类、排序和筛选算法。

## 火：切换周期保持页面稳定

原实现每次切换周期都会清空重建火页面，并重新请求三组组合；组合卡片从加载提示变回卡片时会改变高度。切换期间刷新状态提示的显隐也会影响页面位置。

现在保留扫描容器、周期标签、已加载的组合卡片与展开的数据覆盖区域；更新候选结果和对应表格。只有扫描快照变化才重新读取组合；较旧请求的迟到响应不能覆盖较新的组合。全部同步更新结束后再保持标签栏的位置，避免提示显隐造成跳动。

## 验证

- 26项聚焦测试通过，覆盖原显示规则、刷新行为、保留焦点与展开状态、组合响应先后顺序。
- 浏览器逐页检查九个市场页面，执行32次按钮切换（含8次火周期切换）；选中底色与字色、品种代码的字色、键盘焦点正确，无页面脚本错误。
- 火连续切换八次：扫描容器、标签栏、组合卡片和刷新按钮均保持原节点；记录的132个画面时刻中卡片持续存在、标签栏位置变化小于1像素；额外组合请求为0。
- 四种周期的实际候选代码与原扫描接口逐项一致，铃铛数量与品种数量一致；候选/全部切换和组合详情入口可用。
- 现有桌面程序实际验证资金排行选中按钮、费用页品种代码白字，以及四种火周期连续切换，均通过。使用隔离数据库和验收配置，未操作用户当前窗口。
- 390像素窄屏下品种选择区域无横向溢出。
- 浏览器检查前后正式业务数据库清单一致；所有交互使用隔离数据，未启动扫描、研究、交易或自选写入。
