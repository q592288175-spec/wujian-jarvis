# 顶部快捷添加账户

2026-10-08，十月当前项目。

账户选择旁新增“＋”入口，弹窗填写账户名称、实际账户金额，保存为独立实盘账户并自动切换。账户选择保存到本机，下次打开继续使用。原账户资金、交易卡、成交、复盘和批准不转移、不覆盖。

复用原有账户接口与SQLite存储，不更改正式风控计算。新账户不复制其他账户的档位、批准、冻结预算或持仓；账户档位沿用后台原有未知默认值，必要时在“账户与规则”独立核验。

取消不保存；金额必须为正数，名称不能为空；提交时禁用重复点击；接口失败保留输入并可重试。账户已保存但页面刷新失败时明确提示，避免误认为未保存而重复添加。

验证：198项JavaScript测试通过，包括不同余额独立测算（110万元9手、25万元2手）、原账户不变、新进程重新读取账户一致。WindowsAPP已重建重启，1440/1024/390宽度实际打开与取消弹窗；保存、失败重试、自动切换及重复提交用页面隔离响应验证，正式业务库前后一致，未添加测试实盘账户。

修改：`dist/index.html`、`dist/workbench.js`、`dist/workbench.css`；测试：`tests/simple-account.test.mjs`、`scripts/verify-add-account-desktop.mjs`。页面证据与截图在 `output/add-account-2026-10-08`。
