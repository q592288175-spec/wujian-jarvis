更新：2026-10-10。当前项目：`D:\五简个人资料\2026年10月文件\小木工作台\wujian-jarvis`。

## 定位与当前状态

你交代条件，小木持续核对有效报价，满足后记录证据并通知。它不下单、不改交易计划，也不替代交易软件中的止损保护。火的筛选门槛不影响你明确指定的监控合约。

代码、独立监控库、两版界面和 Windows APP 已接入。确定性规则与隔离模拟、Windows 通知接收、托盘后台、重启持久化已核验。本人飞书扫码及通知单聊已绑定，新测试消息取得飞书成功回执，用户确认手机实际收到。按用户后续要求，当前已选择免账号的新浪公开网页行情；重启后自动恢复，不要求购买天勤年费或填写密码。公开报价约每10秒检查，来源延迟及稳定性无保证；真实交易时段触发仍待核验。六个公告源分别显示覆盖状态，当前不能宣称全市场公告完整覆盖。

本轮没有修改火筛选技能、交易批准、账户金额或默认临时复盘的保存规则。旧分享 ZIP 未重新打包，不包含这次的新功能。

## 开始使用

1. 打开 `.runtime\desktop-build\小木-win32-x64\小木.exe`。左侧“今日总览”下方是“盯盘提醒”；稳定版、全息版右上角共用铃铛和记录。
2. 进入“盯盘提醒 → 连接与通知”，行情源已选“新浪公开行情（免账号）”，需要重新检查时点“连接所选行情”。不需密码或付费试用。只有选择备用“快期 / 天勤（自有账号）”时才出现账号表单；密码仅填 APP，不发到聊天。账号版本及实际权限另行核验，不自动购买服务。
3. 点“飞书扫码绑定”，用本人飞书扫码确认。点击“打开飞书小木”，在本人单聊发送“绑定提醒”，将通知绑定到该单聊；不需要重新扫码。绑定后点“测试手机通知”，核对手机实际收到，再在“提醒记录”查看回执。“通道已接收”不等于手机显示或本人已读。
4. 点“测试电脑通知”。Windows 通知设置、免打扰与通知中心可能影响显示；工作台记录始终保留。
5. 添加提醒，核对具体月份合约、阈值、有效期和通知渠道，点“确认启用”。未配置实时行情时可以保存规则，但页面必须显示待配置，不会拿盘后价伪装实时触发。

也可以直接对文字助手说“提醒我沪铜涨到80000”“关注列表五分钟涨幅超过1%”。助手只建立待确认草稿，点“核对提醒卡”后在页面启用。模糊的“涨得很快”需要补时间窗口、幅度和品种，不自行猜条件。无需模型也可手工建卡，明确的常见提醒语句可直接解析。

合约详情、火候选行和全息版当前品种均有提醒入口，自动带入具体合约。现有盘后主力映射作为配置前的参考列表；连接成功后补入行情源的有效主力映射。列表注明来源，未能核验的合约不宣称受到实时支持。

新浪模式沿用盘后具体主力映射，不把连续合约当成可交易合约，也不声称公开源提供了独立主力换月认证。当前84个已有具体合约映射中81个取得价格和原始报价时间，其中包含8个股指/国债合约；动力煤ZC212、强麦WH303、粳稻JR301旧映射没有报价。未映射或无报价的品种不能冒充已接通。价格取源数据的最新成交字段，不取买一价。完全相同的响应不伪造新样本，保留源日期及时间；晚于30秒的报价不参与触发。只轮询已启用监控的合约，首次连接另做一次全映射可用性检查；失败退避，最高等待5分钟再重试，不绕过网站限制。[AKShare新浪期货接口说明](https://akshare.akfamily.xyz/data/futures/futures.html)

日历复用当前扫描的AKShare日历，每日重新核验覆盖范围；按日盘小节、已知品种夜盘和节前停夜盘区分交易区间。广期所及股指国债不按商品夜盘处理，节前与周末白天不判断。时段表参考[上期所当前交易时间](https://www.shfe.com.cn/services/calenderandholidays/tradinghours/)、[2026年休市安排](https://www.shfe.com.cn/services/calenderandholidays/holiday/)及[南华期货2025年末品种规则简表](https://e-nanhua.com.cn/cmsbigfile/2018/12/3b654c11-a278-4075-9eed-9121cd7571ea/1%E5%93%81%E7%A7%8D%E8%A7%84%E5%88%99%E7%AE%80%E8%A1%A8%E2%80%94%E2%80%94%E7%BB%BC%E5%90%88%E9%99%90%E4%BB%93%E7%89%8820251226.pdf)。交易所后续调整时须更新核验，不将未更新的时段表视为永久准确；还要求当前区间与源报价区间一致、报价新鲜才判断。

## 三种规则

| 类型 | 计算口径 | 触发与重复 |
| --- | --- | --- |
| 价格到位 | 最新成交价达到或高于目标，或达到或低于目标；价格符合最小变动价位 | 默认一次完成；可选择重复及冷却 |
| 短时异动 | 同一合约，1、3、5或15分钟；当前价 / 窗口起点价 - 1 | 默认冷却15分钟；完整窗口、条件曾恢复不满足，才再次触发 |
| 官方公告 | 关注品种的保证金、涨跌停板、手续费、交割及交易时间公告 | 每5分钟检查；新公告或已取得正文的实质修订分别留痕 |

涨价 / 上行红色，跌价 / 下行绿色；异常橙色，公告中性色，均配文字。批量异动与公告按启用时选定的具体成员保存，不随火名单变化自动增删。

价格达到不冒充突破：启用、重启或断线后的第一笔有效报价已满足，只报“当前已达到目标价”。只有同一连续交易区间的前后有效观测才报价格穿越。不会补猜休眠或断网期间发生的路径。

乱序、重复、无效价格、未来时间及陈旧报价不触发；行情中断、换时段、午休和节假日重新积累异动窗口。样本来自实际接收报价，不用日K或人工补价填满短时窗口。报价稀疏时可能长期处于“积累窗口”，这是数据不足，不是监控已正常判断。

主力换月提示复核，原阈值继续绑定原合约，不自动挪到新合约；过期或不可订阅成员显示原因，批量规则的其他有效成员继续运行。到价只监控一个具体合约。

## 后台、费用与安全

- 有已启用规则时首次关闭原生 APP 窗口会询问“后台监控 / 退出并停止”，可记住选择。后台从托盘打开或彻底退出；电脑休眠、关机及真正退出会停止监控，恢复显示中断区间并重新预热窗口。
- 确定性检查不逐笔调用 AI，不产生模型调用费用。模型费用仅涉及主动对话和研究解释。
- 当前使用免登录公开网页行情，本轮未申请付费试用、购买权限或保存行情密码。不能承诺第三方网页永久免费、持续开放或固定延迟；不适用于毫秒级盯盘或止损保障。天勤保留为自有账号的备用选项，其实际权限与版本费用单独核验。[天勤官方说明](https://doc.shinnytech.com/tqsdk/latest/profession.html)
- 服务只监听回环地址，手机通知通过本人飞书白名单，不开放工作台公网端口；提醒消息不带账户权益或私人研究。
- 新行情凭据使用 Electron 系统加密；新飞书绑定使用 Windows 当前用户 DPAPI。它们只供本机当前用户恢复，不能当作可跨机器的凭据备份。未修改既有旧凭据配置的保存位置；新备份不包含凭据。
- Windows 通知按应用标识与快捷方式注册，实际系统设置仍需本人核对。[Electron通知要求](https://www.electronjs.org/docs/latest/tutorial/notifications)

SQLite分别保存规则版本、成员状态、触发证据、通知队列与公告基线。事件与待发通知在同一事务内落库；重启保留冷却及历史，但不续接旧短时样本。中断时已开始发送且无回执的消息标为结果待核对，不盲目重发。飞书明确返回拒绝才有限重试，最多3次；成功按事件去重，仍不代表本人已读。

飞书错误码 `230101` 表示本次发送被平台拒绝。本轮按用户 ID 主动发送时遇到该限制，改为本人已确认的单聊后取得成功回执。单聊只能由当前扫码绑定账号发送“绑定提醒”来登记，并校验应用、用户及会话；不接受他人或群聊绑定。记录随本机飞书配置加密保存；过去失败的测试仍保留，不自动补发，绑定后需发一条新的测试。

监控库与 `.runtime\five-workbench.sqlite` 及盘后行情库分开；Python实时采集器只输出结构化事件流，不覆盖 `.runtime\market.json` 或盘后快照。提醒留痕不会自动记成成交或已保存复盘。

主要接口全部位于 `/api/monitor`：

- `GET /status`、`/contracts`、`/rules`、`/events`、`/events/:id`、`/export`、`/stream`。
- `POST /preview`、`/rules`、`/rules/:id`、`/rules/:id/activate|pause|archive`。
- `POST /events/:id/read`、`/runtime`、`/test`、`/sources/check`、`/export/file`。
- `POST /provider`：选择 `sina` 免账号公开行情或 `tqsdk` 自有账号；切换会清空旧窗口并保存来源选择，不能把两种来源的样本拼接。
- APP专用连接、心跳和通知回执接口；不开放任意代码、账户或下单工具。

规则及重要修改保存为草稿，必须页面确认。AI工具只有提醒草稿、状态、列表查询，不具备直接启用权限。

## 备份与恢复

页面“导出监控备份”直接写入当前 D 盘项目 `output\monitor-backups`，提示实际路径，不使用浏览器默认下载目录。JSON包含规则与事件，不包含行情密码或飞书密钥；提醒内容仍是私人资料，请自行保管。

离线恢复时，先在托盘选择“退出并停止监控”，确认服务已结束。可使用本机 Node，或桌面包内自带 Node 运行模式：

```powershell
Set-Location 'D:\五简个人资料\2026年10月文件\小木工作台\wujian-jarvis'
$env:ELECTRON_RUN_AS_NODE = '1'
& '.runtime\desktop-build\小木-win32-x64\小木.exe' 'scripts\restore-monitor.mjs' 'output\monitor-backups\实际备份文件.json' '.runtime\monitor\restored.sqlite'
Remove-Item Env:ELECTRON_RUN_AS_NODE
```

工具只恢复到项目内一个不存在的新 `.sqlite` 文件，禁止覆盖当前库。旧活动规则默认暂停；未确认的历史通知不补发；窗口样本清空。核对恢复结果后，在本次启动环境指定新库，再打开 APP：

```powershell
$env:WUJIAN_MONITOR_DB = (Resolve-Path '.runtime\monitor\restored.sqlite').Path
Start-Process -FilePath '.runtime\desktop-build\小木-win32-x64\小木.exe' -WindowStyle Hidden
```

该环境变量须持续传给后续 APP 启动；普通快捷方式仍使用默认库，不会自动切到恢复库。推荐保留原库和导出备份，人工复核后才决定正式替换。不要在运行时拷贝或覆盖SQLite主文件；完整目录备份须先正常退出并保留相关WAL文件。

代码回退只从修改前检查点逐文件比对恢复本次相关文件，不整目录覆盖现有用户修改；不要用修改前的 `business-backup.json` 覆盖后来新增账户或成交。
