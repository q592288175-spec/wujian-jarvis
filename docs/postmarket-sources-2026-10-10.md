# 小木盘后消息、产业数据与金十 MCP

日期：2026-10-10。只扩展研究证据，不改三模式筛选、排序、账户或交易权限。

## 使用

1. 火页面刷新盘后数据后，点“盘后数据复盘”。每次重新打开分析，会重新核验消息；正在运行时只查看进度，不重复创建。
2. 报告仍先看市场、板块和三模式对照，再看当天主线、供需变化与反证。“消息与供需变化”可展开原文、交易所指标及来源缺口。
3. 默认临时分析。只有点“保存复盘”才写入 `.runtime/postmarket-reviews/<复盘ID>/`，报告、输入和原网页证据随本次版本固定，历史按保存时间倒序。没有覆盖原6份记录。
4. 小木文字AI已能调用金十：例如“通过金十查原油最新消息”“通过金十读取财经日历”“先确认报价代码，再查现货黄金”。国际现货不能替代国内具体期货合约。
5. 复盘弹窗的“金十连接”可更新本机 Token，不显示现有密钥；下次分析生效。不要把 Token 发给其他人，也不要放入分享压缩包。

## 实际接入

| 来源 | 接入方式与实际覆盖 | 明确边界 |
| --- | --- | --- |
| 财联社 | 12个公开栏目结构化页面，候选相关快讯正文；资讯补读免费原文 | 每栏目最近20条，不是全天全量；验证页面、付费正文不绕过 |
| 金十 | 官方 Bearer Token；2025-11-25标准 MCP 初始化、通知、工具与资源发现、工具调用；优先 structuredContent | cursor / next_cursor 分页，最多8页及5个候选关键词，每次工具调用上限28；权限、额度、失败保留缺口 |
| 上期所仓单 | 指定复盘日原表合计行，保留原单位与原表增减 | 仓单不等于总库存，不能重复叠加小计 |
| 上期所周库存 | 截止复盘日最近周五原表：本期、上期、变化 | 交割库符合交割品质库存含仓单，不是社会或全行业库存；不是每日变化 |
| 上期所席位 | 复盘日具体合约前20名，多空分别汇总 | 多空名单可能不同，不是全市场持仓，不等于资金净流入 |
| 郑商所、能源中心、大商所、广期所 | 官方地址实际尝试；当前未取得通过核验的结果 | HTTP 412、验证页、网络失败或口径未核实都不输出数字 |
| 文华商品指数 | 核验官方 WT9 / 历史接口条件，当前未接通 | 公开历史接口不含当日；授权是否覆盖指数待核验，商品等权样本不冒充该指数 |

所有消息按北京时间核验，晚于复盘日的消息不纳入；15点后的消息单列“盘后信息”，只作次日背景。历史消息保留原日期。引流标题和摘要不作为已核验全文，新闻报道中的产业数值需说明是报道，不能冒充交易所原表。

AI输入不包含引流标题、仅摘要或旧新闻；它们仍可在来源页查看。输出校验要求盘后消息、周报口径及推断标记明确，遇到矛盾先纠正一次，仍冲突则显示AI解释失败，保留真实计算与资料，不伪装成完整解读。

产量、开工、现货、基差、终端需求未取得完整可比数据；有部分公开消息，不代表已打通所有产业数据库。AI只解释已取得证据，引用[S编号]；数值、三模式资格和次日技术验证仍由程序确定。

## 本机与 Codex

小木凭据只在 `.runtime/private/market-sources.json`，读取接口只返回配置状态，不返回 Token；不进入业务操作归档、报告或分享包。该目录已限制本机用户及系统访问。

Codex 已登记 `jin10` Streamable HTTP MCP：`https://mcp.jin10.com/mcp`，通过用户环境变量 `JIN10_MCP_TOKEN` 提供 Bearer 认证，配置文件没有明文 Token。重启 Codex 后，新会话才可加载新增 MCP 工具；本次会话已经通过同一标准协议直接实测。以后更换密钥时，小木连接设置和 Codex 用户环境变量需要同步更新。
