# 天勤连接核验与版本 0.5.1

日期：2026-10-28。发布标签：v2026.10.28.1。

## 本次修复

- 休市时也输出首次取得的有效报价，保留报价原始时间，不伪造跳价。
- 单个合约权限不足单独显示，允许其他合约继续订阅；账号认证失败与网络中断分开处理。
- 登录入口直接填写快期账号密码；Windows 当前用户加密保存，重启恢复，退出清除。
- 统一桌面与网页登录请求超时时间，纠正示例 Python 配置的跨平台路径。
- 应用版本从 0.5.0 更新到 0.5.1。交易规则、账户和历史记录不修改。

## 验证结果与边界

- 52 项 Node.js 聚焦测试通过，覆盖登录、加密保存与恢复、暂停监控保持、同日同合约量价仓接入、失败不泄露密码。
- 5 项 Python 检查通过，覆盖交易时段、合约编码与权限异常隔离。
- 浏览器、全息版和重新构建的 Windows 程序实际启动及点击通过；页面无脚本错误。模拟 SDK 用于可重复验证，未用测试数据覆盖正式行情。
- 本机正式 TqSdk 3.10.2 可导入；HTTPS 合约目录返回 200。认证端点 GET 返回 405（该接口要求 POST），证明服务可达，不代表账号认证成功。
- 正式业务数据库完整性正常，所有表前后指纹一致。
- **真实账号认证和实际报价仍待本人在本机登录后核验。** 当前正式服务仍运行旧桌面版本，未强制关闭未保存编辑。上述自动检查不能替代真实账号权限验证。

## 启用与使用

保存编辑后，通过“小木 → 退出”完全退出，再从桌面快捷方式重开。点击顶部“行情连接”，在本机填快期/天勤账号密码。核对已连接、收到的合约数量和行情时间；密码不发到聊天、不提交仓库。

本机新版桌面构建：`.runtime/desktop-tq-verified-20261028/小木-win32-x64/小木.exe`。本轮备份和验证底稿：`output/tq-release-20261028/`；界面验收：`output/redesign-2026-10-25/tq-release-20261028/`。

发布包为源码版，依赖和本地桌面程序需按教程安装或构建。最新价、涨跌幅、成交量和持仓量使用收到的天勤报价；历史 K 线、席位等继续保留各自来源。账号权限、使用范围及费用以天勤服务为准。

官方接口参考：[TqApi、get_quote 与 wait_update](https://doc.shinnytech.com/tqsdk/latest/reference/tqsdk.api.html)。
