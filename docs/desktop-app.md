# 五简 JARVIS 本机桌面版

使用 Electron 44.4.3，Apple Silicon macOS。构建：`npm run desktop:build`。
应用包生成于 `.runtime/desktop-build/五简 JARVIS-darwin-arm64/五简 JARVIS.app`。

本版是本机应用：包内保存当前项目位置，界面、服务、Python环境和研究数据继续来自原项目。不要单独把.app发给别人，也不要移动或删除项目。项目移动后重新构建即可。密钥不会打进应用包；仍从项目本地.env读取。尚未进行Developer ID签名或公证，不宣称可分发安装版。

打开时检查4318端口是否属于JARVIS，然后启动或复用本地服务。行情采集器使用文件锁防止重复运行。关闭窗口会隐藏应用并保留工作，菜单退出才停止本应用启动的服务；复用的外部服务保持运行。中断的研究需要手动重试，不自动重复模型计费。

安全配置：渲染进程sandbox、contextIsolation开启，nodeIntegration关闭；只允许工作台源在应用内导航，外部HTTP/HTTPS链接在系统浏览器打开。麦克风只允许本地工作台的音频请求，并需用户确认；不开放摄像头或其他默认权限。

语音：当前仍为浏览器识别/合成加DeepSeek，Electron中的实际识别能力待用户测试；GPT-Live尚未配置，也未声称已完成全双工通话。

研究复核页面已用显式验收样例验证输入→保存→读取，验收样例与记录已删除，不进入真实研究历史。39项JS、7项Python测试通过。

## 2026-09-19 实际验收结果

官方运行包 SHA256 校验通过，Apple Silicon 应用已成功构建。已实际验证：打开稳定版、读取既有研究报告、在原Web服务停止后自行启动服务、从无采集器状态连接天勤并恢复61个筛后合约、退出后清理自有Web与行情子进程、立即重开后重新连接。应用保持打开。

启动时会尝试启动采集器，由Python独占文件锁防重，不以新鲜快照推断旧进程仍存活。41项JavaScript测试通过；实际全双工通话仍未接通，本地尚缺OPENAI_API_KEY。桌面应用并非完整独立分发包，仍依赖此项目目录和Python环境。

备份入口：运行 `python3 scripts/checkpoint.py` 生成不含密钥、行情缓存与研究记录的源码检查点。完整源码曾在隔离目录实际恢复启动；研究数据与凭据仍应单独保留。不要用早期部分源码覆盖包作为完整恢复包。
