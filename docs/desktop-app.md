# 小木五简交易系统 Windows 本机版

使用 Electron 44.4.3。Windows 构建：`npm run desktop:build`。当前统一主入口为市场全景，完整交易流程纳入同一界面；全息地球保留在“全息版”。
桌面与开始菜单快捷方式已更新到 `.runtime/desktop-tq-verified-20261028/小木-win32-x64/小木.exe`，新增顶部天勤账号登录入口；当前打开的旧窗口先保存编辑并完全退出，再重新打开生效。详见[天勤登录接入](天勤账号登录接入-2026-10-28.md)、[2026-10-25合并交付](市场全景合并交付-2026-10-25.md)及[手动以损定量与缩放修复](K线与手动以损定量及缩放修复-2026-10-25.md)。

本版是本机应用：包内保存当前项目位置，界面、服务、Python环境和研究数据继续来自原项目。不要单独复制 EXE 或移动、删除项目；项目移动后重新构建即可。密钥不会打进应用包；仍从项目本地 `.env` 读取。当前未签名，不宣称是可分发安装版。

打开时检查4318端口是否属于JARVIS，然后启动或复用本地服务。服务自动维护免费盘后数据，采集器使用进程内互斥防止重复刷新。关闭窗口会隐藏应用并保留工作，菜单退出才停止本应用启动的服务；复用的外部服务保持运行。中断的研究需要手动重试，不自动重复模型计费。

安全配置：渲染进程sandbox、contextIsolation开启，nodeIntegration关闭；只允许工作台源在应用内导航，外部HTTP/HTTPS链接在系统浏览器打开。麦克风只允许本地工作台的音频请求，并需用户确认；不开放摄像头或其他默认权限。

语音：复用现有火山双向语音服务与DeepSeek回答。合成音频的真实识别、模型回答和语音返回已通过验证；实际麦克风与主观听感需在正常使用时核对。旧版验收记录按当时状态保留。

五行贯通流程已在隔离测试业务库完成“火扫描→水研究→金测算批准→土部分成交和平仓→木整轮复盘”，测试记录不进入正式业务库。三张打印页通过浏览器实测。122项 JavaScript 测试、7项 Python 测试通过。

## 2026-09-19 实际验收结果

官方运行包 SHA256 校验通过，Apple Silicon 应用已成功构建。已实际验证：打开稳定版、读取既有研究报告、在原Web服务停止后自行启动服务、从无采集器状态连接天勤并恢复61个筛后合约、退出后清理自有Web与行情子进程、立即重开后重新连接。应用保持打开。
