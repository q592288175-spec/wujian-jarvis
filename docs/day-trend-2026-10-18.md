# 火页面新增日K顺势观察模式

2026-10-18（北京时间），按本人本次明确条件新增。项目为当前十月小木工作台。

## 使用

进入“火·识别机会”，在“周日小周期”右边点击“日K顺势”。四个标签保持原来顺序并新增末项：月周日共振、月周大周期、周日小周期、日K顺势。多头红色在前，空头绿色在后；保留详情、MA10图表、进入水研究和盯盘提醒。

| 方向 | 入选条件 |
| --- | --- |
| 多头观察 | 今日日MA10严格高于昨日日MA10，且今日最低价严格高于昨日最低价 |
| 空头观察 | 今日日MA10严格低于昨日日MA10，且今日最高价严格低于昨日最高价 |
| 共用门槛 | 同一具体主力、最新完成交易日、成交量和持仓量均严格大于10,000手 |

均线走平、高低点相等、量仓任一等于或低于1万手，均不进入候选。今日与昨日指最近两个完成交易日，周一对周五，节假日不拿自然日补判。只在已保存数据完整且同日时计算；陈旧、缺合约、缺昨日数据、量仓日期不一致显示数据不足。

本次没有额外加入日收盘价相对日MA10的位置、周月方向、前天结构、突破或评分门槛。明细日K结构用“今日对昨日”，不沿用其他模式“前天→昨天形成结构，再由今天检验”的三根K辅助口径。辅助高点/低点及其颜色不增加筛选条件。

刷新盘后数据完成后，接口基于新快照重新计算日K模式。原始扫描历史不重写；进入水研究后，新交易卡按原账户机制保存 `scanMode=day-trend`、具体合约、数据日、判定值及本模式规则版本。重复添加复用现有卡，归档卡提示恢复。
