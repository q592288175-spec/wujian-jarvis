# 金第五法：穿分时均线入场

2026-10-26本人按截图确认新增独立分时方法。现行计算版本gold-2026-10-26-v2；10月19日四法规则和历史版本保留，原四法触发与止损计算不改。

本人本次补充确认：第五法仍按各账户最新余额×0.5%核算，截图中的100万元仅作举例，不改为初始资金基数。原账户较严限制、同一机会累计已损及未成交预留继续取小，不重置原轮次。

| 项目 | 第五法口径 |
| --- | --- |
| 定位 | 独立分时小周期；与第四法“分时择机、日K结构管理”分开 |
| 环境 | 已有主线许可，并呈易涨难跌或易跌难涨；不在无方向反复穿线中无限试做；原周日方向与环境核验仍保留 |
| 触发 | 按本人确认的分时均线算法，上穿做多、下穿做空；算法及是否二次确认须逐方案明确，程序不默认成分钟MA10或当日均价线 |
| 初始止损 | 事先标定的当日有效低点或高点外侧，记录所属交易日、取值截止时刻；点数由本人填写，不自动外加一跳；不按新低新高向外移动 |
| 风险 | 最新余额×不超过0.5%，其他更严限制继续生效；100万元示例为5000元，再按止损价差、点值核算手数 |
| 持有 | 默认无隔夜权限，明确日内离场截止。需要隔夜时，单独填理由、截止和确认，并纳入最终人工拍板；不因此取得日K持有或1%额度 |
| 再次试错 | 明确允许条件；未另行审定不自动复入，同一机会累计已损及风险，不新建轮次冲掉损失 |
| 记录 | 保存算法、二次确认、日内高低点与截止、触发/失效、持有和复入安排；实际费用滑点及隔夜结果沿用成交与复盘记录 |

小木先提供五种方法供核对，盘后日K不能证明实时穿线。第五法需要人工补齐分时证据，不以日K数据自动判定该法“已触发”，也不自造分时均线算法。缺参数时不能确认方法或批准计划。

仍按分析→本人确认手法→审定入场、止损和各账户手数→最终拍板。算法、触发、取值范围、止损、日期、持有权限或账户发生变化须生成新版重新审定，原批准不沿用；旧记录不回写，原持仓保护不改。旧锁定轮次保持原保护，新增规则用于完成旧轮次后的新审定，不能自动结束旧轮次。
